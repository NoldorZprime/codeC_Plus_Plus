# Uso de la sentencia continue en C++

La sentencia `continue` en C++ se utiliza dentro de los bucles para omitir la iteración actual y pasar directamente a la siguiente. A diferencia de `break`, que termina el bucle por completo, `continue` solo interrumpe la iteración en curso y sigue con la siguiente repetición del ciclo.

## Sintaxis de continue

```cpp
continue;
```

## Uso en bucles

La sentencia `continue` puede emplearse en bucles `for`, `while` y `do-while` para saltarse ciertas iteraciones según una condición específica.

### Ejemplo con un bucle for

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        if (i == 3) {
            continue; // Salta la iteración cuando i es 3
        }
        cout << "Número: " << i << endl;
    }
    return 0;
}
```

### Salida del programa:
```
Número: 1
Número: 2
Número: 4
Número: 5
```

### Explicación:
- Cuando `i` es igual a `3`, `continue` se ejecuta y el `cout` se omite para esa iteración.
- El bucle continúa con `i = 4` y `i = 5` sin interrupciones.

## Ejemplo con un bucle while

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 0;
    while (i < 5) {
        i++;
        if (i == 3) {
            continue; // Salta la impresión cuando i es 3
        }
        cout << "Valor de i: " << i << endl;
    }
    return 0;
}
```

### Salida:
```
Valor de i: 1
Valor de i: 2
Valor de i: 4
Valor de i: 5
```

### Explicación:
- `i` se incrementa al inicio del bucle.
- Cuando `i == 3`, `continue` salta la impresión y pasa a la siguiente iteración.

## Ejemplo con un bucle do-while

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 0;
    do {
        i++;
        if (i == 3) {
            continue;
        }
        cout << "Iteración: " << i << endl;
    } while (i < 5);
    return 0;
}
```

### Salida:
```
Iteración: 1
Iteración: 2
Iteración: 4
Iteración: 5
```

### Explicación:
- `continue` hace que cuando `i == 3`, se omita el `cout` y se pase a la siguiente iteración.
- Sin embargo, como `i` sigue incrementándose, el bucle no se vuelve infinito.

## Diferencia entre break y continue

| Sentencia  | Descripción |
|------------|-------------------------------------------------|
| `break`   | Sale completamente del bucle, deteniendo su ejecución. |
| `continue` | Omite la iteración actual y pasa a la siguiente. |

### Ejemplo comparativo:

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        if (i == 3) {
            break; // Detiene completamente el bucle
        }
        cout << "Número: " << i << endl;
    }
    return 0;
}
```

### Salida con break:
```
Número: 1
Número: 2
```

- Aquí, cuando `i == 3`, el bucle se detiene completamente, mientras que con `continue` solo se hubiera omitido la iteración.

## Conclusión

La sentencia `continue` en C++ es útil cuando queremos omitir ciertas iteraciones en un bucle sin interrumpir su ejecución completa. Se debe usar con cuidado para evitar bucles infinitos o saltos no deseados dentro del flujo del programa.
