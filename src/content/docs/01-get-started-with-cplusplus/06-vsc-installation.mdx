## ¿Qué es CodeLite?

CodeLite es un entorno de desarrollo integrado (IDE) gratuito y de código abierto, diseñado principalmente para el desarrollo en C, C++ y Node.js. Ofrece compatibilidad con diversas plataformas, incluyendo Windows, Linux y macOS.

## Instalación en Windows

### Paso 1: Descargar CodeLite

1. Visita la página oficial de CodeLite: [https://codelite.org](https://codelite.org)
2. Dirígete a la sección de descargas y selecciona la versión más reciente para Windows.
3. Descarga el instalador en formato `.exe`.

### Paso 2: Instalar CodeLite

1. Ejecuta el archivo descargado (`codelite-setup.exe`).
2. Sigue las instrucciones del asistente de instalación.

CodeLite es un IDE ligero y potente para programadores de C++, C y Node.js. Su instalación es sencilla en cualquier sistema operativo y su configuración inicial es rápida. Con esta guía, ya puedes comenzar a programar con CodeLite de manera eficiente.
